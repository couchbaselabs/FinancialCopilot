Connect to Couchbase Capella

This dashboard requires the Node.js backend running locally. Follow these steps:

  1. Copy .env.example to .env
  2. Fill in your Capella credentials (CB_ENDPOINT, CB_USERNAME, CB_PASSWORD)
  3. Create a bucket named portfolio in Capella
  4. Create a primary index: CREATE PRIMARY INDEX ON `portfolio`
  5. Run npm run seed to load sample data
  6. Run npm start
